# 🧱 Python Foundation & Core Programming

This directory contains standalone Python scripts, data samples, and specialized topic folders covering language fundamentals, collections, data interchange formats, and OOP concepts.

---

## 📄 File Inventory

| File Name | Description |
| :--- | :--- |
| **`demo.py`** | Basic syntax demonstration: variables, operators, string formatting, input prompts, and multidimensional student lists |
| **`dict.py`** | Dictionary operations: creating key-value pairs, accessing properties, and dictionary manipulation |
| **`set.py`** | Set data structures: uniqueness properties, set methods (`update`, `remove`, `discard`), and set operations |
| **`functions.py`** | Conditional decision branching (`if/elif/else`), grading logic, and reusable function concepts |
| **`csv_handling.py`** | File operations using Python's native `csv` library (appending rows, parsing lines) |
| **`data.csv`** | Sample CSV dataset used for file reading and writing exercises |
| **`json_program.py`** | Serializing and deserializing JSON data structures using the `json` standard module |
| **`data.json`** | Sample structured student record in JSON format |
| **`enc.py`** | Encapsulation in Python classes (protecting attributes and providing controlled access) |
| **`file_h.py`** | File handling practice template |
| **`url demo.py`** | Web scraping script using `requests` and `BeautifulSoup` targeting web pages |

---

## 🗂️ Subdirectories

* **[`exception_handling/`](./exception_handling/)**: Error handling patterns (`try`, `except`, `else`, `finally`, `raise`).
* **[`Machine Learning/`](./Machine%20Learning/)**: Jupyter notebooks for machine learning dataset ingestion and exploration.
* **[`npfiles.py/`](./npfiles.py/)**: Vectorized array operations and broadcasting with NumPy.
* **[`oops/`](./oops/)**: Object-Oriented Programming (student management classes, single/multi-level inheritance).
* **[`pandas_practise file/`](./pandas_practise%20file/)**: Extensive Pandas drills covering DataFrame filtering, selection, and aggregation.

## 🏃 Running the Scripts

Execute any script directly via Python:

```bash
python demo.py
python "url demo.py"
```
