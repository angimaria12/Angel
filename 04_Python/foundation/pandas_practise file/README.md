# 🐼 Pandas Data Wrangling & Analysis

This directory contains comprehensive practice drills using **Pandas**, the leading data analysis and manipulation library in Python.

---

## 📄 File Inventory

* **`file_pandas.ipynb`**:
  * An extensive, multi-step Jupyter notebook covering:
    * Creating Pandas `Series` and `DataFrame` objects from Python dictionaries and external files.
    * Data inspection tools: `.head()`, `.tail()`, `.sample()`, `.shape`, `.columns`, `.dtypes`, `.info()`, and `.describe()`.
    * Column selection, renaming, and conditional row filtering.
    * Handling missing values (`NaN`) and data type conversions.
    * Index manipulation, sorting, and slicing techniques.
    * Summary aggregations, frequency distributions (`value_counts()`), and group calculations.

---

## 💡 Practical Applications

Pandas forms the backbone of data cleaning and preparation pipelines in data science, bridging the gap between raw database/file extracts and analytical modeling or machine learning algorithms.

---

## 🏃 How to Run

```bash
pip install pandas jupyter
jupyter notebook file_pandas.ipynb
```
