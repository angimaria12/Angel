# 🏛️ Object-Oriented Programming (OOP) in Python

This folder contains Python implementations demonstrating the principles of Object-Oriented Programming (OOP), structuring software around classes, objects, encapsulation, and inheritance.

---

## 📄 File Inventory

* **`student management.py`**:
  * An implementation of a Student Information & Management System.
  * Models a `Student` entity featuring:
    * Class-level attributes (e.g., `university = "Nova University"`).
    * Instance attributes initialized via `__init__` constructor (`name`, `id`, `dept`, `marks`, `attendance`).
    * Instance methods formatting and displaying student profiles (`display()`).
    * Instantiation and management of multiple student objects.
* **`inh.py`**:
  * Demonstrations of object inheritance:
    * Single and multi-level inheritance structures.
    * Base classes and specialized child classes.
    * Reusing parent class properties and overriding parent methods.

---

## 🧠 Core OOP Concepts Covered

1. **Classes & Objects**: Blueprints for creating objects with state (attributes) and behavior (methods).
2. **Encapsulation**: Bundling attributes and methods into a single unit to protect internal state.
3. **Inheritance**: Creating hierarchical relationships to reuse code without redundancy.
4. **Polymorphism**: Enabling uniform interfaces for methods across derived classes.
