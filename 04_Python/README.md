# 🐍 04. Python for Data Analytics & Engineering

This directory contains practical Python implementations covering language fundamentals, data structures, object-oriented programming (OOP), file I/O, web scraping, data manipulation (NumPy & Pandas), and machine learning workflows.

---

## 📑 Module Overview

Python is the core programming language for modern data analytics, engineering, and data science. This module demonstrates:

* **Core Programming**: Syntax, dynamic typing, control flow (`if/elif/else`, loops), functions, and built-in data structures (lists, dictionaries, sets).
* **Object-Oriented Programming (OOP)**: Class architecture, constructors (`__init__`), encapsulation, and inheritance hierarchies.
* **File I/O & Serialization**: Reading and writing flat files (`.csv`), structured data interchange (`.json`), and error handling (`try/except/finally`).
* **Web Data Extraction**: Web scraping HTML documents using `requests` and `BeautifulSoup`.
* **Numerical Computing with NumPy**: Vectorized array operations, matrix mathematics, and boolean masking.
* **Data Wrangling with Pandas**: High-performance DataFrame indexing, filtering, aggregations, and exploratory data analysis.
* **Applied Machine Learning**: Ingesting real-world datasets and preparing features for predictive modeling.
