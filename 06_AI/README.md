# 🤖 06. Artificial Intelligence & Advanced Analytics

This module is dedicated to applied Artificial Intelligence, Generative AI models, predictive machine learning algorithms, and AI agent engineering.

---

## 🎯 Purpose & Scope

Modern data analysts and engineers increasingly leverage artificial intelligence to automate complex workflows, uncover non-linear relationships in data, and build intelligent end-user experiences. This module focuses on:

* **Predictive Machine Learning**: Supervised and unsupervised modeling (regression, classification, clustering, dimensionality reduction).
* **Generative AI & LLMs**: Prompt engineering, structuring outputs, and leveraging state-of-the-art foundation models (Google Gemini, OpenAI, Claude).
* **Retrieval-Augmented Generation (RAG)**: Combining vector databases with LLMs for intelligent question answering over structured and unstructured company documentation.
* **AI-Driven Automation & Agents**: Building agentic workflows to automate data extraction, transformation, code generation, and automated report drafting.

## 📋 Recommended Roadmap

1. **Applied ML**: Develop end-to-end classification and regression models using `scikit-learn`.
2. **Generative Workflows**: Build automated Python scripts that summarize SQL query results into natural-language business insights.
3. **Agent Integration**: Integrate API-based LLMs to automate data profiling and automated documentation generation.
