# 📦 TrendKart Raw Datasets

This directory holds the raw, unmodified data source workbook for the TrendKart project.

---

## 📄 File Inventory

* **`TrendMart_Fashion_Enterprise_Dataset (1).xlsx`**:
  * Unprocessed multi-sheet enterprise workbook containing the source transactional logs and operational master tables for TrendKart's fashion retail operations.
  * Contains the original raw records prior to anomaly detection, deduplication, and formula normalization.

---

## 📌 Usage Note

Use this file when auditing or rebuilding the ETL cleaning pipeline from scratch, or when demonstrating before-and-after data quality comparisons against `Cleaned/TrendKart_Data_Cleaning.xlsx`.
