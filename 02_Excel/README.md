# 📈 02. Advanced Excel & Business Intelligence

This directory contains advanced spreadsheet analysis, data cleaning pipelines, business data modeling, and interactive dashboards developed in Microsoft Excel.

---

## 📑 Module Overview

Excel remains the foundational tool for exploratory analysis, quick business modeling, and ad-hoc executive reporting. This module demonstrates practical, industry-standard capabilities:

* **Data Cleaning & Auditing**: Formatting standardization, deduplication, handling missing records, and maintaining detailed `Data_Quality_Log` sheets.
* **Relational Data Modeling in Excel**: Joining transactional logs with dimension tables (Customers, Stores, Employees, Suppliers, Products) using dynamic lookups (`XLOOKUP`, `INDEX/MATCH`, `VLOOKUP`).
* **KPI Calculations & Aggregations**: Revenue, cost of goods sold (COGS), gross margins, units sold, discount impacts, and transaction volumes using `SUMIFS`, `COUNTIFS`, and array formulas.
* **Interactive Executive Dashboards**: Pivot tables, slicers, timelines, conditional formatting, and KPI cards designed for executive decision-making.
