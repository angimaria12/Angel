# 📊 Data Analytics & Engineering Portfolio

Welcome to the **Data Analytics & Engineering Portfolio** repository. This repository organizes an end-to-end learning curriculum, enterprise data projects, practical exercises, and business intelligence solutions spanning spreadsheet modeling, relational databases, programming, statistical analysis, interactive dashboards, and artificial intelligence.

---

## 🗂️ Repository Architecture

The workspace is structured into six core modules representing the full lifecycle of data analytics and data science engineering:

```text
Angel/
├── 📁 01_Core_Readiness/        # Analytical reasoning, business fundamentals & interview prep
├── 📁 02_Excel/                 # Advanced spreadsheet modeling, data auditing & executive dashboards
│   └── 📁 Project/              # FreshMart & TrendKart enterprise case studies
├── 📁 03_SQL/                   # Relational database architectures, ETL scripts & BI querying
│   └── 📁 Projects/             # HealthPlus Care & Medicare Hospital operational databases
├── 📁 04_Python/                # Python programming, OOP, data structures & data wrangling
│   └── 📁 foundation/          # Scripts, NumPy, Pandas, OOP, and Machine Learning notebooks
├── 📁 05_PowerBI/               # Interactive enterprise BI reporting & manufacturing dashboards
└── 📁 06_AI/                    # Machine Learning models, LLMs & Generative AI workflows
```

## 🚀 Module Overview

### [01. Core Readiness](./01_Core_Readiness/)
Focuses on business quantitative aptitude, structured problem-solving (root cause analysis, MECE frameworks), core metrics (margins, unit economics, growth rates), and technical interview preparation.

### [02. Excel Analytics & Dashboards](./02_Excel/)
Enterprise-grade spreadsheet solutions featuring data quality audits, complex formulas (`XLOOKUP`, `INDEX/MATCH`, `SUMIFS`), pivot modeling, and interactive KPI dashboards for retail and e-commerce domains.
* **[FreshMart](./02_Excel/Project/FreshMart/)**: Supermarket retail chain data pipeline and sales transaction dashboard.
* **[TrendKart](./02_Excel/Project/TrendKart/)**: Multi-channel fashion apparel sales dashboard with data quality logs.

### [03. SQL & Relational Database Engineering](./03_SQL/)
Complete SQL implementations covering schema design (DDL), ETL data cleansing (DML), data validation scripts, and complex business intelligence queries.
* **[HealthPlus Care](./03_SQL/Projects/HealthPlus/)**: Healthcare network database tracking clinics, consultations, telemedicine, and chronic care programs.
* **[Medicare Hospital Analytics](./03_SQL/Projects/Medicare/)**: Comprehensive hospital operations database covering admissions, appointments, doctors, lab tests, pharmacy, and billing.

### [04. Python for Data Analytics](./04_Python/)
Python foundational programming and scientific computing libraries:
* **Core & OOP**: Data structures (lists, dicts, sets), functions, exception handling, and object-oriented programming.
* **Data Wrangling**: Numerical computing with **NumPy** and exploratory data analysis with **Pandas**.
* **Automation & Web Scraping**: Data extraction using `requests` and `BeautifulSoup`.
* **Machine Learning**: Exploratory model workflows and predictive modeling foundations.

### [05. Power BI Solutions](./05_PowerBI/)
Production-ready Power BI reporting models (`.pbix`) featuring star-schema data models, advanced DAX measures, and responsive dashboard design:
* **`AeroHouse.Manufacturing.pbix`**: Aerospace manufacturing throughput, scrap rates, and equipment efficiency.
* **`NoviTech_Manufacturing.pbix`**: Industrial plant productivity, inventory turnover, and fulfillment tracking.

### [06. Artificial Intelligence & Generative AI](./06_AI/)
Applied AI, predictive modeling, machine learning algorithms, and integration of generative AI / LLM APIs.

## 🛠️ Technology Stack & Tools

* **Spreadsheet Modeling**: Microsoft Excel (Power Query, Pivot Tables, Dynamic Arrays, Data Validation)
* **Databases & Querying**: MySQL / PostgreSQL (DDL, DML, Window Functions, Stored Queries, CTEs)
* **Programming**: Python 3.x (`pandas`, `numpy`, `beautifulsoup4`, `requests`, `openpyxl`)
* **Business Intelligence**: Microsoft Power BI Desktop (DAX, Star Schema, Custom Visuals)
* **Version Control**: Git & GitHub
