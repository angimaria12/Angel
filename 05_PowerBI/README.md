# 📊 05. Power BI & Enterprise Business Intelligence

This directory contains production-grade Microsoft Power BI reports (`.pbix`) delivering interactive manufacturing analytics, operational intelligence, and executive KPI scorecards.

---

## 📑 Module Overview

Power BI bridges data modeling, DAX calculations, and visual storytelling. This module showcases enterprise reporting solutions in manufacturing operations:

* **Star Schema Modeling**: Architecting facts and dimensions (Time, Production Lines, Machines, Products, Operators) for optimal DAX performance.
* **DAX Measures**: Advanced calculations for Overall Equipment Effectiveness (OEE), throughput volume, scrap and defect rates, downtime percentages, and rolling time-intelligence comparisons.
* **Executive Visualization**: Customized interactive dashboards with drill-through views, hierarchical slicers, conditional formatting, and card indicators.

## 🛠️ How to Open & Explore

1. Install **Microsoft Power BI Desktop** (latest version recommended).
2. Double-click either `.pbix` file to launch the report.
3. Explore the interactive visual canvas, toggle filters via the on-canvas slicers, and inspect the data relationships in the **Model View**.
